# Projeto integrador economia circular
Sobre o projeto
O Futuro Sustentável é uma aplicação web criada para incentivar práticas sustentáveis por meio da reciclagem, reutilização de materiais e consumo consciente.
A proposta é apresentar aos usuários informações sobre economia circular, demonstrando como pequenas atitudes podem contribuir para a preservação do meio ambiente e para a construção de um futuro mais sustentável.

Funcionalidades implementadas:
Alternância entre tema claro e escuro;
Navegação por seções da página;
Conteúdo educativo sobre economia circular;
Botão interativo com dica sustentável;
Formulário de participação;
Layout responsivo;
Estrutura semântica em HTML.

Tecnologias utilizadas:
HTML
CSS3
JavaScript

  OBJETIVO:
  Promover a conscientização ambiental e incentivar hábitos sustentáveis, mostrando a importância da economia circular para
  a redução de desperdícios, preservação dos recursos naturais e melhoria da qualidade de vida das futuras gerações.
